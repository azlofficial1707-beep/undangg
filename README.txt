UNDANGAN DIGITAL PREMIUM — PANDUAN

MULAI
1. Ekstrak ZIP.
2. Buka folder undangan-digital-premium.
3. Buka index.html dengan Chrome / browser.
4. Panel pengaturan berada di bagian paling bawah halaman.
5. Isi nama, tanggal, orang tua, lokasi, link Maps, dan nomor WhatsApp RSVP.
6. Pilih foto dan musik untuk preview di perangkat Anda.

FILE UNTUK WEBSITE ONLINE
Letakkan file Anda di folder assets dengan nama:
- foto-cover.jpg
- pria.jpg
- wanita.jpg
- galeri-1.jpg
- galeri-2.jpg
- galeri-3.jpg
- musik.mp3

Foto cover akan digunakan untuk latar halaman pembuka dan foto utama. Gunakan JPG/PNG/WebP dengan ukuran yang wajar agar cepat dibuka di HP.

NAMA PENERIMA
Link undangan bisa dipersonalisasi dengan parameter:
https://domainanda.com/?to=Andi
https://domainanda.com/?to=Keluarga%20Pak%20Budi

PENTING TENTANG PANEL EDITOR
File yang dipilih melalui panel editor hanya menjadi preview sementara di browser yang sedang digunakan. Browser tidak mengunggah file ke internet dan perubahan tidak otomatis tersimpan ke hosting.
Untuk undangan online, ganti file dalam folder assets dengan file final Anda (gunakan nama file di atas), lalu unggah seluruh folder ke hosting statis seperti Netlify, GitHub Pages, atau hosting Anda sendiri.

RSVP WHATSAPP
Masukkan nomor WhatsApp di panel dengan kode negara tanpa tanda + atau spasi, contoh 6281234567890. Form RSVP akan membuka WhatsApp dengan pesan yang sudah disiapkan.

KUSTOMISASI LANJUTAN
Warna, tipografi, teks acara, jam, dan detail orang tua dapat disesuaikan langsung pada index.html. Musik akan mulai setelah pengunjung membuka undangan karena browser umumnya memblokir autoplay sebelum interaksi.
